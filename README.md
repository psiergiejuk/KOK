# KOK BASIC

> **K**ode **O**n **K**anvas – Minimalistyczne środowisko BASIC dla dzieci i pasjonatów retro.

<img width="282" height="331" alt="Zrzut ekranu z 2026-10-18 22-38-08" src="https://github.com/user-attachments/assets/0fffecb9-8801-4737-a788-7d225009620e" />


**KOK BASIC** to lekka, pełnoekranowa aplikacja napisana w Pythonie (Pygame), stworzona z myślą o bezstresowej nauce programowania dla dzieci. Projekt inspirowany jest klasycznymi systemami 8-bitowymi oraz systemem MMBasic z urządzeń typu PicoCalc.

Pozwala dzieciom tworzyć własne rysunki, animacje i proste gry 2D za pomocą prostych komend, bez rozpraszaczy, wyskakujących okienek i skomplikowanych konfiguracji.

---

## ✨ Główne Cechy

* 🚫 **Zero rozpraszaczy:** Pełnoekranowy tryb pracy (Edytor ↔ Program).
* 🎨 **Prosta grafika:** Łatwe rysowanie kształtów (`CIRCLE`, `RECT`, `LINE`) i obsługa kolorów.
* ⌨️ **Dwa tryby:**
  * Wpisz kod w edytorze i wpisz `RUN`, aby uruchomić program.
  * Wciśnij `ESC` w dowolnym momencie, aby wrócić do edycji kodu.
* 🖱️ **Obsługa inputu:** Proste sterowanie myszką i klawiaturą do tworzenia gier.
* 🔊 **Dźwięk i multimedia:** (W trakcie rozwoju) obsługa prostych efektów dźwiękowych.
